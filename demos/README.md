# Leptos Motion Demos

This directory contains organized demonstrations of the leptos-motion library.

## Structure

### Basic Demos (`demos/basic/`)
- **`reactive-demo/`** - Interactive reactive animation demo with controls
- **`minimal-demo/`** - Minimal showcase of basic animations

### Advanced Demos (`demos/advanced/`)
- **`webgl-demo/`** - WebGL-powered 3D animations
- **`gestures-demo/`** - Advanced gesture handling and animations

### Showcase Demos (`demos/showcase/`)
- **`comprehensive-demo/`** - Full-featured demonstration of all capabilities

### Legacy Demos (`demos/legacy/`)
- **`v0.7-showcase/`** - Legacy v0.7 demonstrations
- **`phase2-comprehensive-demo/`** - Phase 2 development demos
- **`phase2-reactive-demo/`** - Phase 2 reactive demos
- **`performance-demo/`** - Performance testing demos
- **`simple-working-demo/`** - Simple working examples

## Running Demos

Each demo can be run independently:

```bash
cd demos/basic/reactive-demo
trunk serve --open
```

## Demo Selection Guide

- **New to leptos-motion?** Start with `demos/basic/minimal-demo`
- **Want to see reactive animations?** Try `demos/basic/reactive-demo`
- **Need advanced features?** Check `demos/advanced/`
- **Want to see everything?** Run `demos/showcase/comprehensive-demo`
