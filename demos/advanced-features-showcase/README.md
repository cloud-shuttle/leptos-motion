# 🎨 Leptos Motion Advanced Features Showcase

A comprehensive demonstration of all 4 advanced animation systems in Leptos Motion:

## ✨ Features Demonstrated

### 🎭 Variants System
- Named animation states with reusable definitions
- Smooth transitions between variants
- Type-safe variant management

### 🎬 Keyframes System
- Multi-step animations with intermediate states
- Smooth interpolation between keyframes
- Configurable timing and easing per keyframe

### ⚡ Stagger Animations
- Sequential element animation effects
- Configurable timing patterns (Forward, Backward, Center, Edges)
- Automatic delay calculation for cascading effects

### 🎯 Timeline Orchestration
- Complex animation sequences with precise timing
- Multiple tracks running simultaneously
- Event callbacks for timeline milestones

### 🎊 Combined Demo
- All 4 systems working together
- Staggered card reveal with variants
- Complex multi-layered animations

## 🚀 Running the Demo

```bash
cd demos/advanced-features-showcase
trunk serve --open
```

The demo will be available at `http://localhost:8084`

## 🎯 Navigation

Use the navigation buttons to switch between different animation systems:

- **Variants**: Button state animations
- **Keyframes**: Multi-step ball movement
- **Stagger**: Sequential item reveals
- **Timeline**: Orchestrated multi-property animations
- **Combined**: All systems working together

Each demo section includes code examples showing how to use the respective animation system in your Leptos components.
